# 🤖 Mon Robot Trading

Bot de trading automatique en Python — DCA crypto + analyse RSI sur actions US.

## ⚙️ Fonctionnalités

- **DCA crypto** : achats réguliers de BNB / ETH / BTC
- **Trading actions US** : analyse RSI, signaux d'achat/vente
- **Notifications Telegram** : alertes en temps réel
- **Historique** : suivi des positions et des trades

## 🛠️ Stack

- **Python 3.14**
- **Termux** (Android) pour l'exécution 24/7
- **Stockage** : JSON local

## 🚀 Installation

```bash
git clone https://github.com/hrvb78-sys/mon-robot-trading.git
cd mon-robot-trading
pip install -r requirements.txt
python bot.py
